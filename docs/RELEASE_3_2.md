# Проверки релиза 3.2 «Висла»

**Версия документации: 3.2 · Дата: 26 октября 2026 года.**

[README](../README.md) · [История изменений](../CHANGELOG.md) · [Отдельные замеры](performance-3.2.json)

## Проверки поведения

- Пройдены 173 модульных теста: расчёты, данные, переводы, экспорт, хранение и согласованность версии.
- Пройдены 60 браузерных сценариев: 32 для настольного Chromium и по 14 для мобильных Chromium и WebKit.
- После последних изменений мобильных стилей дополнительно повторены 14 проверок раскладки, касаний и крупного текста.
- Проверены ширины 320, 360, 390, 430 и 768 px, русский и английский интерфейс, все темы, текст 200%, поворот экрана, настройки, прокрутка матрицы, прохождение теста, ссылка на результат и скачивание JSON.
- Сценарии появления графиков и поворота экрана дополнительно повторены по три раза после исправления замечаний CI.
- Проверены раннее приветствие при задержке загрузки приложения и описание без JavaScript.
- Обновлены три скриншота README, проверены ссылки текущей документации и `git diff --check`.

## Производительность

Сравниваются исходники 3.1.1 и пакет 3.2. Обе версии обслуживались одним локальным сервером по HTTPS с gzip; Lighthouse 13.5.0, стандартный мобильный профиль, замедление CPU ×4. Для каждой версии выполнены три запуска после завершения браузерных тестов. Ниже медианы. Первые HTTP-замеры с вмешательством локального антивируса в таблицу не включены.

| Показатель | 3.1.1 | 3.2 |
| --- | ---: | ---: |
| Performance | 70/100 | 94/100 |
| Accessibility | 97/100 | 100/100 |
| Best Practices | 100/100 | 100/100 |
| SEO | 100/100 | 100/100 |
| LCP | 5.50 с | 2.97 с |
| Total Blocking Time | 236 мс | 69 мс |
| CLS | 0.000 | 0.009 |
| Передано при загрузке | 623 КиБ | 286 КиБ |

В отдельном сценарии с CPU ×4 максимальная длительность зарегистрированного взаимодействия — 200 мс (21 событий). Проверялись переход к тесту, начало, ответ, следующий вопрос, переход к голосованиям и открытие/закрытие настроек. Это лабораторная выборка Event Timing, а не INP реальных посетителей.

## Ограничения

- Performance ≥90 достигнут во всех трёх запусках. LCP ≤2,5 с пока не достигнут: медиана 2.97 с. CLS остаётся ниже 0,1.
- SEO 100 означает прохождение автоматических технических проверок, а не гарантированное место в поиске.
- WebKit проверялся в эмуляции. Проверка на физическом iPhone не выполнялась.
- Полевые Core Web Vitals и изменение поискового трафика требуют статистики после публикации. Счётчики и отправка ответов пользователей не добавлялись.
- Политические данные, экспертные оценки, формулы и формат ссылок не изменялись. Этот релиз не подтверждает актуальность политических источников.

## Публикация

GitHub Actions проверяет расчёты и поведение подготовленного пакета. Публикация в GitHub Pages выполняется после успеха обоих наборов тестов. Имена пакетов содержат хеши для обновления кэша при новом выпуске.
