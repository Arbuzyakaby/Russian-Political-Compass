# Проверки релиза 4.0 «Тиса»

**Версия документации: 4.0 «Тиса» · Обновлено 26 октября 2026 года.**

## Поведение и выпуск

- До изменений: 173 модульных теста и 60 браузерных сценариев на 3.2, без ошибок.
- После изменений: 194 модульных теста, 0 failed.
- Исходники: 84 браузерных сценария, 0 failed. Подготовленный dist: те же 84 сценария, 0 failed. 48 сценариев настольного Chromium и по 18 мобильных Chromium/WebKit.
- Мастер всех шести шагов, цвет/эмблема, мини-компас, голосования, собственный маркер, гостевая ссылка в чистом профиле и явное сохранение, импорт/экспорт, лимит шести партий и отмена удаления.
- Безопасное отображение строк, похожих на HTML/скрипты, в карточках, селекторах, радаре и SVG; загрузка PNG проверяется по сигнатуре и размерам.
- Резервная копия не принимает дубликаты id, неверные настройки, null вместо ответов или неполный черновик. Старые форматы SRPC проходят backup → restore. Сброс данных очищает и память, и хранилище.
- Палитра переходит к конкретному голосованию и исходным настройкам; история и skip-link работают с клавиатуры. Выбор радара, редактируемый черновик и настройки размера маркеров сохраняются после перезагрузки/перерисовки.
- SRPC: раскладки не перекрываются, измерения и сведения о файлах доступны, цикл и масштаб сохраняются, экспорт SVG скачивается, карточки прокручиваются касанием вне рукоятки.
- Карта заменяется списком координат. Щипок проверен настоящими touch-событиями CDP в Chromium; в WebKit проверен обработчик двух касаний. Увеличенный SVG не перекрывает кнопки сброса.
- Все пять вкладок проверены на ru/en, шести темах и ширинах 320/390/768/1280. Дополнительно проверены 360/430, текст 200%, мастер на 320/390, пасхалки с общим выключателем и ограничением движения.
- Окно обновления с 3.2 сохраняет заголовок и список 4.0 после поздней инициализации; английский подвал показывает 4.0 “Tisza”. Обновлены четыре скриншота документации.
- Два агента отдельно проверили код/регрессии и соответствие плану. Замечания устранены и повторно подтверждены: потери черновика и коллекции, гостевая точка, радиусы маркеров, автопереход, палитра, начальная загрузка своих партий, режим списка и синхронизация SRPC. Добавлены регрессионные проверки.
- Подготовка пакета и git diff --check выполнены. CI и публикация проверяются после релизного пуша.

## Производительность

Свежие пакеты 3.2 (b25d297) и 4.0 обслуживались одним локальным сервером по HTTP с gzip. Lighthouse 13.5.0, мобильная симуляция, стандартное замедление CPU ×4. По три последовательных холодных запуска на выпуск; ниже медианы. Браузерные тесты во время итоговых измерений не выполнялись.

| Показатель | 3.2 | 4.0 |
| --- | ---: | ---: |
| Performance | 77/100 | 77/100 |
| Accessibility | 100/100 | 100/100 |
| Best Practices | 81/100 | 81/100 |
| SEO | 100/100 | 100/100 |
| LCP | 4.55 с | 4.78 с |
| Total Blocking Time | 116 мс | 58 мс |
| CLS | 0.009 | 0.005 |

Исторический отчёт 3.2 использовал HTTPS и другой запуск; его оценки не смешиваются с текущим сравнением. Локальный HTTP влияет в том числе на Best Practices и не описывает защищённый публичный сайт. Увеличение трафика связано с новыми модулями, интерфейсом и словарём. Это измеренная стоимость новых функций, а не подтверждение ускорения всего приложения.

## Ограничения

- Цель LCP ≤2,5 с в этой локальной конфигурации не достигнута. Полевые Core Web Vitals не измерялись; лабораторный прогон не является INP реальных посетителей.
- WebKit и мобильные размеры проверялись в эмуляции; физический iPhone не использовался.
- В Resource Timing размер из кэша может быть неизвестен; при наличии используется decodedBodySize. Один пакет JS участвует в нескольких звеньях SRPC, поэтому размеры звеньев нельзя складывать как независимый трафик.
- P1 ограничен 1800 символами. Для длинной программы приложение предлагает JSON. Коллекция локальная: очистка хранилища браузера удаляет её; доступна резервная копия.
- Политические данные реальных партий и формулы теста не переоценивались. Пользовательская партия и гипотетическая палата — введённый посетителем сценарий.
