# Политический компас партий РФ

Интерактивная визуализация позиций российских партий на двух осях — экономика (лево/право) и отношение к государству (либертарианство/этатизм). Плюс тест, который ставит на ту же сетку вас.

Текущая версия — **1.3.0.1**, список изменений в [CHANGELOG.md](CHANGELOG.md).

## Возможности

- Компас с позициями партий и подсказками при наведении
- Список партий с фильтрами («Все» / «В Госдуме» / «Без мандатов») и поиском
- Карточка партии: координаты, лидер партии, ключевые тезисы, обоснование позиции
- Переключение созыва Госдумы (IV–VIII, 2003–2021) с историческими данными по мандатам
- Тест на 40 утверждений с координатами и списком партий по близости
- Карточка результата для соцсетей: мини-компас, координаты и топ-3 партии,
  форматы 1:1 и 16:9, рисуется в браузере через Canvas
- Слой траекторий: стрелки показывают, как позиции партий смещались во времени
- Экспорт данных: компас в PNG и SVG, партии и мандаты в CSV, всё в JSON
- Вкладка «О проекте»: методика координат, что проект делает и чего не делает
- Системная, светлая и тёмная тема; адаптивная вёрстка под мобильные экраны
- Полоса прочтения, липкая полоса вкладок, подсветка карточки под курсором,
  кнопка возврата наверх и уведомления о сохранённых файлах
- Стили печати: на бумагу уходит содержание, а не интерфейс
- Появление блоков при прокрутке, счётчики в KPI-плитках и прорисовка линий
  графика — всё отключается при `prefers-reduced-motion`
- Подвал с разделами, справкой по данным и ссылкой на исходный код

## Разделы

Страница разбита на три вкладки, состояние вкладки хранится в адресе (`#/compass`, `#/quiz`, `#/about`).

### Компас и аналитика

Под компасом — четыре KPI-плитки и три графика, которые следуют за выбранным созывом:

- **Состав палаты** — парламентская диаграмма: 450 точек-мандатов, места расставлены
  слева направо по экономической оси, поэтому дуга читается как политический спектр.
  Фракция определяется по ближайшему месту, так что навести можно на любую часть дуги;
  клик открывает карточку партии.
- **Динамика мандатов, IV–VIII созывы** — линии по итогам выборов 2003–2021 с курсором,
  подсказкой по созыву и приростом относительно прошлых выборов; переключатель
  «мандаты / доля палаты», клик по графику меняет созыв на всей странице.
  Разрыв линии означает, что партии в том созыве не было. Есть таблица данных.
- **Идеологический спектр** — те же координаты, развёрнутые в две расходящиеся шкалы.

В карточке партии — мини-график мандатов по всем созывам.

Кнопка «Траектории» включает необязательный слой: пунктирные стрелки показывают, как
позиция партии смещалась во времени — например, дрейф риторики «Единой России» с 2003
по 2021 год или сдвиг «Справедливой России» после объединения с «За правду». Точки
маршрута подписаны годами, по наведению видно, что изменилось в тот момент.

Кнопка «Экспорт» отдаёт данные файлами: компас в PNG и SVG (с текущим созывом, фильтром,
темой и слоем траекторий), партии и мандаты в CSV, траектории по годам и полный набор
в JSON. Файлы собираются в браузере и никуда не отправляются.

### Тест

40 утверждений: 20 про экономику и 20 про роль государства, ответ по пятибалльной шкале
согласия. Результат — две координаты по тем же шкалам, что и у партий, мини-компас
с вашей точкой и список партий, отсортированный по расстоянию до неё. Ответы и результат
хранятся в `localStorage` браузера и никуда не отправляются; пройденный тест добавляет
вашу точку на большой компас.

На экране результата собирается карточка для соцсетей: мини-компас с вашей точкой,
координаты, название квадранта и тройка ближайших партий. Картинка рисуется через
Canvas в двух форматах — 1:1 для ленты и 16:9 для превью ссылки, — её можно сохранить
файлом или отправить через системное «Поделиться».

### О проекте

Зачем нужны две оси, откуда берутся координаты партий, как читать данные о мандатах,
как считается результат теста и какие у модели ограничения.

## Запуск

Проект статический, сборка не требуется. Достаточно открыть `index.html` в браузере или поднять локальный сервер:

```bash
python -m http.server 8000
```

и открыть `http://localhost:8000`.

## Тесты

Проверяется логика, не отрисовка: данные партий, счёт теста, форматирование,
сборка файлов экспорта, шаг сетки и раскладка мест в парламентской диаграмме,
а также связка разметки со скриптами. Зависимостей нет — работает встроенный
тест-раннер Node (нужен Node 18 или новее):

```bash
npm test          # либо: node --test "tests/*.test.js"
```

Модули проекта не экспортируются, а дописывают себя в `window.PC`, поэтому
`tests/harness.js` исполняет их в контексте `vm` с минимальными заглушками
браузерных объектов. Всё, что требует настоящего DOM — раскладка подписей
компаса, отрисовка графиков, Canvas-карточка, — проверяется в браузере руками.

## Структура

```
index.html
css/    — стили: токены темы, шапка, каркас и вкладки, компас,
          боковая панель, графики, тест, «О проекте», подвал,
          ui.css — слой оформления страницы и стили печати
tests/  — автотесты на встроенном раннере Node и обвязка к ним
js/     — data.js       данные партий и созывов, общие выборки по ним
          utils.js      геометрия компаса, форматирование, localStorage
          ui.js         полоса прочтения, липкие вкладки, уведомления
          theme-boot.js применение темы до первой отрисовки
          theme.js      переключатель «системная / светлая / тёмная»
          nav.js        вкладки и маршрут в адресной строке
          motion.js     появление при прокрутке и счётчики чисел
          compass.js    отрисовка компаса и раскладка подписей
          charts.js     KPI, парламент, динамика мандатов, спектр
          sidebar.js    список партий и карточка партии
          quiz-data.js  40 утверждений теста
          quiz.js       прохождение теста, подсчёт и результат
          tooltip.js    подсказка над точкой компаса
          share.js      карточка результата для соцсетей (Canvas)
          export.js     экспорт данных и картинки компаса
          app.js        состояние, фильтры, инициализация
```

Тема по умолчанию системная: берётся из `prefers-color-scheme` и меняется вместе
с настройкой ОС, пока пользователь не выберет светлую или тёмную вручную.

Координаты партий — экспертная оценка на основе программ и публичной риторики; материал не является агитацией.
