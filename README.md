# Политический компас партий РФ

**Make Compass Great Again.**

**Где находятся российские партии — по словам и по делам.** Интерактивная карта, парламентская аналитика, ключевые голосования и тест политических взглядов в одном статическом приложении.

[Открыть сайт](https://rupolitcompass.website) · [English version](https://rupolitcompass.website/en/) · [README in English](README.en.md) · [История изменений](CHANGELOG.md)

**Текущая версия — 5.1 «Нарев»** · Русский и английский интерфейс · Исходники без сборки, публикация пакетом

## Что можно сделать

Четыре раздела — компас, тест, голосования и «О проекте». В 5.0 проект вернулся к корням; в 5.1 «О проекте» стал короткой книгой, обучение написано заново, голосований стало 44 — у каждого ссылка на протокол Госдумы.

| Раздел | Возможности |
| --- | --- |
| Компас | Сравнить 11 партий по экономике и отношению к государственной власти; посмотреть реальные и заявленные позиции, карточки партий и политических деятелей, центр палаты. Устроить дуэль двух партий: расстояние, восемь шкал, совпадения по темам и созывам и законопроекты, по которым разошлись их фракции. |
| Аналитика | Переключить IV–IX созывы, изучить распределение 450 мандатов, динамику состава Думы и профили по шести под-осям. |
| Коалиции | Собрать набор фракций и увидеть большинство, центр тяжести и показатели выбранной группы. |
| Голосования | Изучить 44 законопроекта 2004–2025 годов и сравнить позиции фракций; у каждого — протокол голосования Госдумы. «Голосую сам»: проголосовать, отметить важное, увидеть, кто голосовал так же, поделиться ссылкой на свои ответы. |
| Тест | Ответить на 20, 40 или 90 утверждений; получить координаты, разбор ответов и сравнение с партиями. |
| О проекте | Книга из двенадцати глав и трёх приложений: оси, методика, голосования, тест, ограничения, история версий; поиск, закладка и печать. |
| Обучение | «Быстрый старт» на пять шагов и «Полный тур» на двенадцать — по самой странице, с продолжением после перезагрузки. |
| Экспорт | Сохранить компас в PNG или SVG, данные — в CSV или JSON; поделиться ссылкой на результат теста. |

Шесть тем оформления и системная тема, акцентный цвет поверх любой темы, настройки читаемости и доступности, управление с клавиатуры и адаптивная вёрстка — в обоих языках интерфейса. Опубликованный сайт после первого визита открывается и без интернета, а значки интерфейса собраны из одного набора [Lucide](https://lucide.dev) (ISC).

## Как выглядит проект

### На телефоне

С 5.0 телефонная версия устроена как нативное приложение: крупный заголовок раздела и круглая кнопка настроек, подписанная карта во всю ширину, сегменты фильтра без переносов, сгруппированный список партий и карточка партии, которая выезжает снизу листом и смахивается вниз. Подписи кнопок и строк не переносятся посреди слова — либо помещаются, либо обрезаются многоточием.

<img src="docs/images/mobile.png" alt="Компас на телефоне в версии 5.0" width="390">

### Дуэль партий и «Голосую сам»

Две партии можно сравнить в одном окне — по позициям, шкалам и голосованиям фракций, а по 28 законопроектам — проголосовать самому и увидеть, чья фракция голосовала так же. Дуэль открывается по ссылке вида `#/duel/er-kprf`; дуэль и «Голосую сам» подгружаются, только когда понадобились.

![Дуэль ЛДПР и «Справедливой России»](docs/images/duel.png)

![Блок «Проголосуйте сами» с рейтингом фракций](docs/images/selfvote.png)

### Результат теста

Координаты сопровождаются объяснением расчёта и списком ближайших партий. На скриншоте — демонстрационные ответы, а не результат автора проекта.

![Демонстрационный результат короткого теста](docs/images/quiz-result.png)

Скриншоты компаса и телефона обновлены для версии 5.0 с локально запущенного сайта, остальные — с 4.3: эти разделы в 5.0 не менялись. Результат теста демонстрационный.

## Запустить локально

Нужен Node.js 22 или новее. Установка пакетов для запуска и модульных тестов не требуется.

```sh
git clone https://github.com/Arbuzyakaby/Russian-Political-Compass.git
cd Russian-Political-Compass
npm run serve
```

Откройте [localhost:4173](http://localhost:4173). Для запуска исходников сборка и установка зависимостей не нужны: приложение состоит из HTML, CSS и JavaScript. При публикации GitHub Actions объединяет и минифицирует файлы, проверяет пакет и отправляет его в GitHub Pages.

```sh
npm test
```

Браузерные проверки запускаются отдельно; подготовка описана в [руководстве разработчика](docs/DEVELOPMENT.md#проверки). Ширина страницы при тексте 200% на 320 px проверяется командой `npm run check:fonts`, мёртвый код ищет `node scripts/find-dead.cjs`.

## Данные и ограничения

Координаты партий — экспертные оценки. Они помогают сравнивать позиции, но не являются объективным измерением или рекомендацией, за кого голосовать. Процент совпадения в тесте вычисляется из расстояния на карте; это не вероятность поддержки партии.

Исторический созыв меняет данные о мандатах, но не превращает текущие координаты партий в исторические. Отсутствие фракции и отсутствие сведений о её голосовании показаны разными состояниями. Подробнее — в [методологии](docs/METHODOLOGY.md).
